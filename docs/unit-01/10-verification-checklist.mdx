# Section 10: Final Environment Setup Check

Before Unit 2, confirm the items for the workflow you chose.

:::info A simulator-first setup is complete
Android Studio is not part of the required checklist. It is only a recommended head start for students preparing to join an advanced team workflow. If local setup caused serious issues, using Telemark's built-in simulator is the correct fallback and you may continue the curriculum.
:::

---

- [ ] Telemark lessons and simulators open in a supported browser
- [ ] I know that the built-in simulator remains available if local setup becomes a serious blocker
- [ ] I know which tool my team uses to deploy Java to the Robot Controller
- [ ] I understand that browser simulation does not install code on a Control Hub
- [ ] My `DiagnosticOpMode` builds in OnBot Java, Android Studio, or my team's supported workflow
- [ ] I can open the Robot Controller's Program and Manage page while connected to its network

If you use Android Studio, also confirm:

- [ ] Android Studio Ladybug 2024.2 or a later version supported by the current FTC SDK is installed
- [ ] The team repository completes a Gradle sync and build
- [ ] The project still uses the SDK's shared build configuration
- [ ] Team code remains at the Java compatibility level supplied by the SDK

The exact SDK and Android settings can change between releases. Check the official FTC repository when your team updates its Robot Controller software.
