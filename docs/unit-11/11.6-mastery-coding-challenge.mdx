# Stage 10: Artifact Capacity and Interlocks

Finish `ArtifactSensors.java`, then use its state to coordinate Intake, Transfer, and Launcher. The robot may control at most three artifacts at once.

## Your Task

1. Map the storage sensors in `ArtifactSensors.init()` and read them in `update()`.
2. Count sensor transitions rather than counting every loop where a sensor remains active.
3. Clamp or guard the stored count from zero through three.
4. Expose `hasCapacity()` and a ready-artifact query.
5. Stop intake or transfer when storage is full, and launch only when an artifact is ready.
