# Lesson F1.5: Coding Challenge: Retrieve and Deliver

Collect the red practice object and release it inside the green delivery zone. Your program must use a color or distance sensor command and move the attachment. It must finish without hitting the orange obstacle or a wall.

Use slow, short test runs while finding the approach. A successful path should control the object before attempting the full delivery.
