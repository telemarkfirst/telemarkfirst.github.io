# Lesson F0.1: What FLL Challenge Is

An FLL Challenge team does more than program a robot. Teams design and explain their robot, develop an Innovation Project, and demonstrate Core Values. This extension focuses on the code used in the Robot Game.

During a match, the robot acts autonomously. A team launches a program from home, the robot attempts missions, and the team may handle it again only as the current rules allow. The full match lasts 150 seconds, so route length and mechanism time both matter.

## Official hardware activity

Read the current [FIRST LEGO League overview](https://www.firstinspires.org/programs/fll/) and open the [current Robot Game materials](https://www.firstinspires.org/resources/library/fll/season-materials). Current rules and challenge updates always override a practice curriculum.

## Simulator practice

Run the starter stack. The robot begins in the blue home region and moves without a gamepad or remote command. Use Step to connect each movement block to a change on the field.
