# Lesson F0.2: The SPIKE App and Telemark Simulator

The [official SPIKE App](https://education.lego.com/en-us/downloads/spike-app/software/) connects to the Prime Hub, configures ports, and downloads Word Blocks or Python. Telemark is a separate browser practice tool. Its blocks teach matching ideas, but its downloaded JSON files open only in Telemark.

The simulator provides Run, Pause, Step, Reset, import, download, a movable 3D camera, pose, sensor readings, match time, and score. A saved workspace belongs to one lesson and remains in this browser unless you download it.

## Official hardware activity

Open the SPIKE Prime tutorials for the motor, color sensor, distance sensor, and force sensor. Find the connected device panel and identify every occupied port on your team's Hub.

## Simulator practice

Run the starter, orbit the field, then reset. Download the workspace, change its distance, and import the saved version again.
