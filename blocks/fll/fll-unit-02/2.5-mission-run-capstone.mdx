# Lesson F2.5: Coding Challenge: Mission Run Capstone

Complete all three reusable-field objectives: cross the dark line, activate the yellow target with the attachment, and deliver the red object to the green zone. Return to the blue home region within 150 simulated seconds.

Your program must call a My Block and return home in at least two of the three fixed wheel-calibration profiles. Build and test one objective at a time, then combine them only after each short route is understood.
