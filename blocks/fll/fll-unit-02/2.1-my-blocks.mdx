# Lesson F2.1: My Blocks and Parameters

SPIKE My Blocks name a reusable stack of commands. A parameter lets one definition work with different values, such as `drive measured distance` called with 30 cm and later 55 cm.

Keep a My Block focused on one job. Mission names are useful for a full route, while action names such as `square on wall` or `close tool` are useful for reusable behaviors.

## Official hardware activity

Complete [My Code, Our Program](https://education.lego.com/en-us/lessons/prime-competition-ready/my-code-our-program/) in the Competition Ready unit.

## Simulator practice

Define a function with one distance parameter. Put a drive block in its body, then call it twice with different values.

## Try it in the SPIKE App

Create My Blocks for your team's repeated drive, turn, and attachment actions. Give parameters units in the name or documentation so centimeters and degrees are not confused.
