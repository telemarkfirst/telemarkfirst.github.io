## What this extension covers

FIRST LEGO League Challenge combines the Robot Game, Robot Design, an Innovation Project, and Core Values. This optional Telemark extension focuses only on programming an autonomous Robot Game robot. The current Founders Edition uses SPIKE Prime technology in two-and-a-half-minute matches.

Complete Blocks Units 0 through 4 first. Unit 5 is useful if you also plan to move into FTC Java, but it is not required here.

Every coding activity works in Telemark without a physical set. Each lesson also points to the official SPIKE App and LEGO Education activity that should be used with a real Hub. Telemark files cannot be imported into the SPIKE App.

## Official companion, not a replacement

Use the [LEGO Education Competition Ready unit](https://education.lego.com/en-us/lessons/prime-competition-ready/) for official builds and classroom activities. Use the [FIRST season materials](https://www.firstinspires.org/resources/library/fll/season-materials) for the current rulebook, updates, and field details.

The 3D field is a reusable practice environment. It does not reproduce BIOGLOW missions or official scoring. It also cannot model wheel slip, battery condition, construction tolerances, or attachment flex. Verify every competition program on your team's robot.

The 2026-27 season is the final season under the current FIRST LEGO League program name. See [FIRST K-8 programs for 2027 and beyond](https://www.firstinspires.org/programs/k-8) for transition information.
