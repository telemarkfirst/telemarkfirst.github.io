# FLL Official Resources

Official sources last checked August 29, 2026.

- [FIRST LEGO League overview](https://www.firstinspires.org/programs/fll/) explains the current program editions and match format.
- [BIOGLOW season materials](https://www.firstinspires.org/resources/library/fll/season-materials) contains the current Robot Game Rulebook, challenge updates, field setup, scoresheets, and guided mission code.
- [FIRST technical resources](https://www.firstinspires.org/resources/library/fll/technical-resources) links supported robot and programming resources.
- [LEGO Education Competition Ready](https://education.lego.com/en-us/lessons/prime-competition-ready/) is the official nine-lesson SPIKE Prime competition unit.
- [LEGO Education SPIKE App](https://education.lego.com/en-us/downloads/spike-app/software/) provides the official Word Blocks and Python programming canvas.
- [FIRST K-8 programs for 2027 and beyond](https://www.firstinspires.org/programs/k-8) explains the announced transition after the 2026-27 season.
