# Curriculum References

This course teaches common programming ideas in Telemark's own words and practice system. Its order was checked against established introductory curricula and Blockly guidance.

- [Code.org Computer Science Fundamentals](https://code.org/cs/curriculum/computer-science-fundamentals) covers sequence, events, conditions, loops, variables, and functions across its elementary courses.
- [Code.org Courses A-F Curriculum Guide](https://code.org/files/CSF_CoursesA-F_Curriculum_Guide.pdf) provides a grade-based scope and sequence for those concepts.
- [Code.org Minecraft: Voyage Aquatic](https://studio.code.org/s/aquatic/lessons/1/levels/1) informed the visible grid, forward movement, turns, and one-action-at-a-time playback in Telemark's original robot field.
- [Scratch Getting Started Guide](https://resources.scratch.mit.edu/www/guides/en/scratch-getting-started-guide.pdf) introduces events and repeated actions, then points learners toward conditions, variables, lists, and custom blocks.
- [Blockly teaching findings](https://developers.google.com/static/blockly/publications/papers/TenThingsWeveLearnedFromBlockly.pdf) describe the need for a clear path from blocks into text code.
- [Blockly documentation](https://docs.blockly.com/) defines the editor behavior used by Telemark's practice workspace.

These sources inform the progression. Telemark's explanations, examples, challenges, and checks are original.
