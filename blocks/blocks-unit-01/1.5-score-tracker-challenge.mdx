# Lesson 1.5: Coding Challenge: Score Tracker

Build a score tracker that finishes with a variable named `score` equal to 12. The program must print `Score: 12`.

Use at least one assignment and one change or math expression. Keep `score` as a number while you calculate. Join it with text only when you create the visible output.

Predict every value of `score`, run the program, and compare your trace with the variables panel. Every visible check must pass to record the full unit.
