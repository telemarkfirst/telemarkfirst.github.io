# Lesson 2.5: Coding Challenge: Package Sorter

Build a sorter that prints `accept` for the chosen package data and does not print `reject` in that same run.

Store at least one package value in a variable. Use a comparison inside an `if` or `if else` block. You may combine conditions when the package must meet more than one rule.

Write the rule in one clear sentence before building. Test one accepted case and one rejected case. Return to the accepted data before running the visible challenge checks.
